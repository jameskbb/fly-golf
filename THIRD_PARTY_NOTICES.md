## MaleCNS v1.0 connectome (data, not redistributed)

- **Credit:** the MaleCNS collaboration, including FlyEM at HHMI Janelia, the University of
  Cambridge Department of Zoology, the MRC Laboratory of Molecular Biology and Google Research,
  plus the authors and contributors named on the release.
- **Release:** https://male-cns.janelia.org/download/
- **Paper:** https://doi.org/10.1016/j.cell.2026.08.015
- **License:** Creative Commons Attribution 4.0 International (`licenses/CC-BY-4.0.txt`,
  https://creativecommons.org/licenses/by/4.0/)
- **Files used:** the flat-connectome feathers (body annotations, neurotransmitter predictions and
  connectome weights at synapse confidence ≥ 0.5). `make data` downloads them into the git-ignored
  `data/raw/`.
- **Changes made by Fly Golf:**
  - the nodes are filtered with Fly Golf's node rule (assigned superclass, not Glia; 166,700
    neurons retained) and every edge between retained neurons is kept;
  - the edges are compiled into a CSR graph with sign × count × 0.275 mV weights;
  - proxy sensory populations and motor readout populations are selected;
  - for the web app's brain map, cell-body (soma) positions are projected and binned (see below).

  These are modelling transformations. They are not measurements, and the dataset creators have
  not validated them.
- **Not committed:** no raw or compiled connectome data is in this repository. It contains only
  checksums (`data/malecns_v1.lock.json`), cell-type names used in documentation, experiment
  outputs, and one small derived anatomy map.
- **Derived map (committed, CC BY 4.0):** `apps/web/public/anatomy/malecns-brain-somata.json`
  (about 21 kB), generated by `services/sim/scripts/build_soma_map.py` from the body annotations'
  soma locations. It holds the number of brain cell bodies in each 1,000-voxel cell of a projection
  of the brain seen from behind, which cells hold the somata of each Fly Golf sensory/motor
  population, and the soma positions of the 18 named readout neurons (by body ID). It holds no
  connectivity and no activity, and it carries the MaleCNS v1.0 attribution in its `attribution`
  field and in the view that draws it.

## DOOMFLY (adapted code in the legacy engine)

- **Source:** https://github.com/nftechie/doomfly, commit `71ecf53d78eaffaf1a57ed7b0ccf5d458abc9f33`
- **License:** MIT, Copyright (c) 2026 nftechie and DOOMFLY contributors (`services/sim/licenses/DOOMFLY-MIT.txt`)
- **Adapted code still in Fly Golf:**
  - `services/sim/src/fly_golf/brain/malecns/legacy_engine.py`: the Numba LIF `_advance` kernel
    (engine `lif-doomfly-r2-adapted-v1`). It is kept unchanged so that records made with it
    replay exactly and readouts trained on it run on the engine they were fitted to. It is **not**
    used for new shots.
- **Adapted in early versions, since reimplemented in Fly Golf** (no DOOMFLY code remains in these
  files; see [docs/DOOMFLY_DECOUPLING_AUDIT.md](docs/DOOMFLY_DECOUPLING_AUDIT.md)):
  - the LIF engine: `engine.py` (`fly-golf-lif-v1`), written from the Shiu et al. model
    specification;
  - the transmitter-sign proxy: `transmitters.py`;
  - the importer and compiler: `data/compiler.py` and `data/prepare.py`. The node rule was first
    taken from DOOMFLY and is now a documented Fly Golf decision; three standard idioms (sorted-ID
    lookup, stable-sort CSR row pointers, float32 `count × sign × 0.275`) coincide;
  - the data lock: `data/malecns_v1.lock.json`, regenerated by `fly-golf-data lock` against the
    official release. The digests are facts about the official files and are unchanged.
- **Never used:** Doom/ViZDoom code, game assets, the retinal projection, the learning rules and
  the UI.

## Shiu et al. (2024) whole-brain LIF model (model lineage)

- Shiu, P. K. *et al.* (2024). A Drosophila computational brain model reveals sensorimotor
  processing. *Nature* 634, 210–219. https://doi.org/10.1038/s41586-024-07763-9
- **License of the reference implementation:** MIT, Copyright (c) 2023 Philip Shiu and Nico
  Spiller (`licenses/Shiu-model-MIT.txt`).
- Fly Golf's engine (`engine.py`, `fly-golf-lif-v1`) implements this model's equations and
  constants from its published specification and reference implementation; no code was copied.
  The legacy engine follows the same model.
- **Brian2** (CeCILL-2.1) runs the reference equations as a test oracle only: it is an optional
  `reference` dependency group, used to regenerate `tests/fixtures/lif_reference.json`, and is
  never a runtime dependency.
