# Data: MaleCNS v1.0

Nothing in `data/raw/` or `data/compiled/` is committed; git ignores both. The only committed
file is `malecns_v1.lock.json`, which holds the source URLs, sizes and SHA-256 digests.

## One command

```sh
make data            # or: pnpm run data   or: uv --directory services/sim run fly-golf-data prepare
make data-status     # what exists, what is missing
```

`make data`:

1. Checks `data/raw/malecns_v1/` for the three source files.
2. Downloads any missing file from the public Janelia/Google bucket (~1.1 GB total). No
   account, token or license click-through is required; the data is CC BY 4.0.
3. Verifies each file's SHA-256 against `malecns_v1.lock.json`, and refuses to continue on a
   mismatch.
4. Compiles the simulation-ready graph into `data/compiled/malecns_v1/` in about 15 s with Fly
   Golf's compiler (`services/sim/src/fly_golf/data/compiler.py`; the node and edge rules are in
   [docs/PROVENANCE.md](../docs/PROVENANCE.md#compiled-graph)):

| File | Contents |
| --- | --- |
| `ptr.npy` | CSR row pointers, int64, length 166,701 |
| `post.npy` | postsynaptic index per edge, int32, 25,582,938 |
| `weight.npy` | synapse count × sign × 0.275 mV, float32 |
| `counts.npy` | raw synapse counts, uint32 |
| `ids.npy` | MaleCNS body IDs, int64 |
| `neurons.feather` | per-neuron annotations (type, superclass, side, transmitter, …) |
| `manifest.json` | counts, policies, source hashes, `matches_expected` |

## The lock

`malecns_v1.lock.json` is generated by Fly Golf against the official release:

```sh
uv --directory services/sim run fly-golf-data verify-source --remote   # local files vs lock, lock vs official bucket
uv --directory services/sim run fly-golf-data lock                     # regenerate (dry run; --write to replace)
```

`lock` sends a HEAD request for each official object, checks that the local file has the size and MD5
the bucket publishes (`Content-Length`, `x-goog-hash`), computes SHA-256, compiles the files to
record the expected neuron, edge and contact counts, and stamps the lock `generated_by:
fly-golf-data lock`. Nothing in it is copied from another project.

After compiling, the backend enables the **MaleCNS** controller. Without data, the app still runs
with the clearly labelled MOCK controller, and the UI shows the fix command.

## Manual download

If automatic download fails, for example behind a proxy:

```sh
mkdir -p data/raw/malecns_v1 && cd data/raw/malecns_v1
B=https://storage.googleapis.com/flyem-male-cns/v1.0/connectome-data/flat-connectome
curl -L -o annotations.feather       $B/body-annotations-male-cns-v1.0-minconf-0.5.feather
curl -L -o neurotransmitters.feather $B/body-neurotransmitters-male-cns-v1.0.feather
curl -L -o edges.feather             $B/connectome-weights-male-cns-v1.0-minconf-0.5.feather
cd - && make data   # verifies checksums, then compiles
```

On Windows PowerShell, run the same three URLs with `Invoke-WebRequest -OutFile`, then
`pnpm run data`.

## Resources

- **Disk:** about 1.1 GB for the raw files and about 350 MB compiled.
- **RAM:** compiling peaks at roughly 4 GB. Running the MaleCNS controller uses about 1 GB, and
  the arrays are memory-mapped.
- **Location:** override it with `FLY_GOLF_DATA_DIR`.
